## 現在の開発環境

2026-10-26、①土台作成は完了。②ではSheetsの8表初期化・読込、非公開Driveの検証とWebP登録・取得、Gemini画像生成用アダプターを実装した。専用GASの本人限定試験配置で初期記録の表示と再読込を確認済み。テスト用WebPの実配信を確認済み。Geminiの認証・モデル一覧取得は成功したが画像生成はHTTP 429。当時の画像用モデルにはAPI無料枠がなく、無料プランでの待機・再試行では解決しない。別アカウント拒否は未確認。ゲーム機能・最終受入は未完了。画像生成は廃止し、画像素材なしのカード表示と対戦後のAIセリフへ再設計した。現行Web v2の画像コード撤去とテキストAIは未実装。旧画像生成のHTTP 429は待機課題から外す。今回の実装開始時にはGit管理情報が存在し、既存のタスク文書の未コミット変更を保持して作業した。

Node.js 22以上を用意し、プロジェクトルートで実行する。検証環境はWindows・Node.js v24.21.0・npm 11.19.0。依存バージョンはpackage-lock.jsonで固定する。

```powershell
npm ci
npx playwright install chromium
npm run check
```

Chromiumが既に導入済みならブラウザのインストールは不要。初回ダウンロードを含む環境準備と、外部サービスへの接続は別である。

| コマンド | 実行内容 |
|---|---|
| npm test | Nodeの40テスト。GASモック・API・画面通信・構造 |
| npm run build | srcの24実行ファイルと.claspignoreをdistへ出力。転送・デプロイしない |
| npm run test:browser | build後にChromiumで360px幅・読込・通信失敗・キーボード再試行を確認 |

Makefileは上記npmコマンドのラッパーへ更新した。Windowsではnpmを直接使える。run/devはモックプレビューであり、GASそのもののローカル実行やホットリロードではない。

プレビューのテストデータ・通信ブリッジはscripts/tests内にのみ置き、配布物に含めない。画面上にもローカルプレビューであることを表示する。GAS向けの実コードは設定不足・未接続時に成功を返さない。

ブラウザのスクリーンショットと結果は `artifacts/scaffold-mobile.png`、`artifacts/scaffold-retry.png`、`artifacts/scaffold-browser-result.json` に出力する（Git対象外）。秘密情報や実データは使用しない。

### ②の接続設定

専用GAS・Sheets・Driveを作成し、.clasp.jsonは今回のGASとdistを指す（Git対象外）。JANKEN_の2設定は保存済み。Geminiのキーは提供者が設定し、モデル名も保存済み。外部通信を追加認可してモデル一覧取得に成功したが、画像生成はHTTP 429。[②のタスク](tasks/03_active/foundation-02-integration.md)に接続先と実測を記録する。claspは3.4.1で固定した。

| Script Property | 用途 |
|---|---|
| JANKEN_SPREADSHEET_ID | 今回専用の8表を置くブック |
| JANKEN_DRIVE_FOLDER_ID | 廃止。現行v2の参照は撤去タスクで除去する |
| GEMINI_API_KEY | AIセリフを使う場合のみ必要。既存値を表示・コピーしない |
| GEMINI_IMAGE_MODEL | 廃止。GEMINI_TEXT_MODELへコード上で流用しない |
| GEMINI_TEXT_MODEL | テキスト用モデル。新設計・未実装 |
| JANKEN_AI_TEXT_ENABLED | 明示的trueで生成。未設定・falseでは定型文。新設計・未実装 |

`inspectConfiguration_()` は名前と設定有無だけを返す内部診断。値は返さず、設定の書換えもしない。外部アダプターは実装済み。設定の存在だけでは疎通成功とせず、実データで確認する。元アプリのScript ID・Deployment ID・接続設定をコピーしない。

## テキストAIの接続と確認

画像生成・WebP変換・画像登録・画像配信は廃止する。画像用モデルのHTTP 429を待機課題にせず、課金設定や再試行を前提にしない。標準の図形カードを先に完成させる。

テキスト候補は `gemini-3.1-flash-lite`。2026-10-26確認の[公式料金表](https://ai.google.dev/gemini-api/docs/pricing)には通常テキスト入力・出力の無料枠がある。アカウント・地域・割当による利用可否は未確認。既存のGEMINI_API_KEYを使う場合も、画像モデルの成功・失敗からテキストの可否を推定しない。

実装後、試験用コピーでROUNDを保存し、getBattleLineで一言を取得する。キー・モデル・有効化設定はScript Properties、生成に送る値はサーバーの保存済み結果から作る。1対戦1試行・日次20試行のアプリ上限、自動再試行なし、429で当日停止を検証する。利用料金の変更や有料モデルへの自動切替はしない。

名前・図形の標準カードと定型文を先に表示し、AIが返るまで画面や保存を止めない。入出力条件・復旧・新APIは[AIセリフ設計](specs/ai-battle-dialogue.md)を参照する。これは設計であり、現行v2にgetBattleLineはまだない。

### ③の管理コマンドと画像処理の廃止

旧scripts/convert-webp.mjsは撤去対象。画像制作・アップロード・登録を新しいセットアップ手順に含めない。

`npm run build` 後の `node scripts/operator.mjs backup` は検証済みバックアップ、`restore BACKUP_ID` は別コピーへの復元検証、`verify` は試験用コピーだけに決定的な1行を追記して再送・バックアップ・復元を確認するエディタ専用ビルドを作る。verifyはコピー3冊を作り、元の接続先やActionsを変えない。200件に達した元データでは追加試験できない。

実行は従来どおりartifacts/operatorからclasp push、エディタのoperatorRunを1回実行する。終了後はエディタでserver/operator-run.gsを削除して通常distをpushし、存在しないことを確認する。管理ビルドからデプロイ・版作成をしない。生成HTTP 429の再試行や課金設定変更をこれらの操作に含めない。
