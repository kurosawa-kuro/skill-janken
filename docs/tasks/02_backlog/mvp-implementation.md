# スキルじゃんけんラボ MVP実装

## Goal

本人限定・P001の1プレイヤー・200行動までの試遊アプリを実装し、[要件のGolden Path](../../01_requirements.md)と[AC01〜AC23](../../07_test_strategy.md)を実機・テスト用データで確認する。

## Context

2026年10月26日の企画・仕様・設計v1.0をdocs/01〜08へ反映済み。同日、①土台作成を実装し、ローカル16テスト・ビルド・Chromium確認が成功した。②で専用GAS配置・Sheets初期化・初期画面表示まで確認済み。テストWebP実配信も確認済み。Gemini画像生成はHTTP 429で課金・割当確認待ち。ゲーム機能・最終受入は未完了。約8時間は準備済み環境での目標であり、完了実績ではない。

2026-10-26の提案で、[既存GASの比較調査](../01_idea/既存GASアプリの比較と写真日記基盤の流用構想.md)から「土台作成→実サービス疎通→土台拡張」を実行タスクへ分割した。本書はMVP全体の親タスクとし、基盤作業の詳細・証跡は子タスクへ集約する。①は05_doneへ移動済み。②は03_activeへ移動し、実環境疎通を進行中。

## Scope

仲間3体、基本スキル3種＋合成1種、固定レシピ1件、5画面、Sheets保存、採用WebP7枚、実データの学習表示、本人限定配置・バックアップを対象とする。課金・対人戦・複数プレイヤー・一般公開・遊び中の生成は含めない。詳細は[要件](../../01_requirements.md)。

## Skeleton

[アーキテクチャ](../../02_architecture.md)のCode / GameService / Rules / Repository / Assets / Adminと、Index / Styles / Clientの責務を維持する。①で実ファイル構成と配置・検証方法を決める。写真日記を主な部品コピー元とし、英語トレーナーのロック保護・保留要求処理を補助利用する。
