# 画像・合成機能撤去と、管理画面で事前生成する対戦セリフ

## Goal

画像なしで成立するゲームと、提供者が事前生成・確認・採用したAIセリフを実装する。プレイ中のリアルタイム生成は禁止。対戦時のセリフ専用通信も追加しない。

## Context

2026-10-26、利用者がGASの待ち時間を理由に対戦時生成を不許可とした。対戦保存後の別RPC生成も撤回し、管理画面で準備する方式へ変更する。[現行設計](../../specs/ai-battle-dialogue.md)と[判断](../../adr/0002-pre-generated-dialogue.md)を正本とする。

src・scripts・testsの実装とローカル検証は完了。GASは旧Web v2のままで、配置・実生成・最終受入は未完了。画像機能廃止は既存Drive素材やActionsの削除を意味しない。

## Scope / Skeleton

- 管理：9枠（仲間3体×勝敗3種）から選択 → 1枠最大3候補を生成 → 下書き保存 → 提供者が確認・選択 → 採用集を公開。
- ゲーム：bootstrapで採用集を一括取得 → playRoundで保存 → ブラウザ内で該当文を選択・表示。
- 採用文なし：組込み定型文。Gemini呼出し・追加RPC・自動補充なし。
- 画像機能、旧getBattleLine案、3秒待ち、ROUND単位の生成予約を撤去／不採用とする。
- 課金変更・自由チャット・自由プロンプト・AIによるゲーム効果決定・一般公開は対象外。

## Plan

- [ ] 旧ブックと旧保留要求を自動変換しない。別の新規ブックで累計スコアを開始し、切替前のバックアップ・検証・データセット別保留隔離を確認する。

- [x] services/assets.js・画像用gemini.js・client/core/assets.html・convert-webp.mjsと画像用operatorコマンドを撤去。isPrivateOwned_はsetup/backup用にcore/access.jsへ移す。
- [x] admin.jsのimageFolder_必須処理、generateFirstAsset_・registerWebp_・updateAssetRow_を除去。画像設定なしでsetupとバックアップを確認する。
- [x] adapters/external.js・settings.js・API・include許可リスト・scripts/files.mjsを同期し、getAssetを除去。旧getBattleLineは実装しない。
- [x] Assets/assetIdの互換性を保持しつつゲーム依存を外す。3体・3スキルの図形／名前と9種の定型文を実装する。

### 2. セリフ管理画面と事前生成

- [x] 本人限定の管理画面とadminApiを追加。全管理操作でJANKEN_ADMIN_EMAILとSessionの利用者を照合し、空欄・不一致を拒否する。ゲームapiと管理操作を分離する。
- [x] 9枠一覧、1枠の候補生成、下書き表示、採用選択、公開、採用解除を実装。生成だけで自動公開しない。
- [x] DialogueDrafts / DialoguePublicationの追加初期化・読取・公開版競合・1行公開と再読込照合を実装。旧8表のデータは維持する。
- [x] テキスト生成アダプターを管理サービスだけに接続。固定キャラと想定勝敗のみを送り、実対戦記録や自由入力を送らない。
- [x] 40文字・日本語・制御文字・HTML・URL等の検証とtextContent描画を実装。提供者が確認した文のみ採用できるようにする。
- [x] 管理要求のUUID予約・重複防止・内容ハッシュ・日次20試行・429等で当日停止・最大200予約を実装。外部通信前にロックを解放し、自動再試行しない。
- [x] GEMINI_API_KEY / GEMINI_TEXT_MODEL / JANKEN_AI_TEXT_ENABLEDは管理生成専用とする。AI無効化で採用集を無効にしない。

### 3. ゲーム表示・運用・検証

- [x] bootstrapへ採用済みdialogueCatalogだけを同梱し、ゲーム内では取得済み集から選択する。起動・対戦・再送・履歴・不足時の生成経路がないことを確認する。
- [x] 同一版・同一requestIdで文の選択が安定し、対戦保存成功後に表示されることを確認。採用集なし／破損は定型文で続行する。
- [x] バックアップ・復元・ハッシュ照合へ管理2表を追加。旧8表だけの復元も確認し、採用集なしでゲームを再開できるようにする。
- [x] 画像用テストを新仕様へ置き換え、保存・権限・再送系を維持。npm run checkと障害注入を実行する。
- [ ] 管理画面で実テキスト生成・内容確認・公開を検証し、無料枠で利用できない場合は事実を記録する。課金を自動有効化しない。
- [ ] 実GAS反映ではリモート残存画像コードを除去し、通常distとの一致・本人限定設定を確認する。実機でGolden Pathとプレイ中の生成ゼロを検証しdocs/07へ記録する。
