# DB再設計：型付き行動記録と非破壊移行

## Scopeと判断

- 現行ゲームは画像・合成なし、1人・200行動・3仲間・3スキル・6適性。
- 旧8表に残る廃止機能と入力／結果／状態JSONの重複を解消する。
- ゲーム6表、物理スキーマ2、型付きActions15列。状態は初期所有と履歴から復元する。
- GASでの1操作1行保存、再送、排他、AIの事前生成を維持する。
- 旧DBを上書きしない。合成廃止後の物理1・マスター2だけ別ブックへ進行を移す。マスター1は旧ルールで読取り保管。
