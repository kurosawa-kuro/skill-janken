# スキルじゃんけんラボ MVP実装

## Goal

本人限定・P001の1プレイヤー・200行動までの試遊アプリを実装し、[要件のGolden Path](../../01_requirements.md)と[AC01〜AC26](../../07_test_strategy.md)を実機・テスト用データで確認する。

## Context

2026年10月26日の企画・仕様・設計v1.0をdocs/01〜08へ反映済み。同日、①土台作成を実装し、ローカル16テスト・ビルド・Chromium確認が成功した。②で専用GAS配置・Sheets初期化・初期画面表示まで確認済み。テストWebP実配信も確認済み。旧画像生成はHTTP 429。後の利用者指示で画像機能は廃止し、テキストAIへ変更する。ゲーム機能・最終受入は未完了。約8時間は準備済み環境での目標であり、完了実績ではない。

2026-10-26の提案で、[既存GASの比較調査](../01_idea/既存GASアプリの比較と写真日記基盤の流用構想.md)から「土台作成→実サービス疎通→土台拡張」を実行タスクへ分割した。本書はMVP全体の親タスクとし、基盤作業の詳細・証跡は子タスクへ集約する。①は05_done。②は別アカウント確認待ち。画像生成は廃止した。利用者の「次進んで」により③を03_activeへ移し、保存・再送・復元の独立部分を先行した。40ローカル試験と実GASの試験用コピー保存・再送・復元照合に成功。画像の一連確認は廃止により範囲外へ移し、[画像撤去・AIセリフ](ai-battle-dialogue.md)を先行実装タスクに追加した。設計のみで新仕様の完了にはしない。

## Scope

仲間3体、初期習得の基本スキル3種、適性6行、消費しない累計スコア、4画面、Sheets保存、画像素材なしのカード表示と管理画面で事前生成したAIセリフ、実データの学習表示、本人限定配置・バックアップを対象とする。課金・対人戦・複数プレイヤー・一般公開・画像生成・自由チャットは含めない。詳細は[要件](../../01_requirements.md)。

## Skeleton

[アーキテクチャ](../../02_architecture.md)のCode / GameService / Rules / Repository / Dialogue / Adminと、Index / Styles / Clientの責務を維持する。①で実ファイル構成と配置・検証方法を決める。写真日記を主な部品コピー元とし、英語トレーナーのロック保護・保留要求処理を補助利用する。
