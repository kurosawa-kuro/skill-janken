# ADR 0003: スキル合成を廃止し、ポイントを累計スコアにする

2026-10-26。採用。物理スキーマを維持する判断は後続の[ADR 0004](0004-rebuild-game-database.md)で更新した。以下は決定当時の記録。利用者が、合成したスキルの画像生成という目玉がなくなったため合成をゲーム仕様から外すよう指示した。

合成画面・固定レシピR01・上位スキルS04・ALWAYS_BONUS・ポイント消費・公開synthesizeを廃止する。後回しの機能やオプションとして残さない。画像生成廃止と、管理画面でのセリフ事前生成・確認・採用は継続する。

新ゲームは仲間3体・基本スキルS01〜S03・適性6行・4画面と結果モーダル。全スキルを最初から習得済みとし、所有する仲間の適性に応じて1つ選ぶ。勝ち2点・あいこ1点・負け1点に条件一致の+1を加える。pointsは0から増える累計スコアであり、通貨・消費・交換・解放条件にしない。

1対多のPlayers→Actionsと、多対多のCharacters↔Skillsは維持する。CharacterSkillsはC01→S01/S02、C02→S02/S03、C03→S01/S03の6行。旧F04・UI04は廃止番号として欠番にし、既存AC07・AC08・AC15を撤去・互換性・固定適性の確認へ改訂する。

保存の列と状態JSONの形は保ちschemaVersion=1、新規マスターはmasterVersion=2とする。旧masterVersion=1の4スキル・9適性・R01・SYNTHESIS・記録内のポイントは旧ルールで読み取り／バックアップ照合する。過去のハッシュ・行・数値を修正しない。新ゲームは新規ブックで開始し、旧ブックを自動上書き・自動変換・自動接続切替しない。旧版を接続した新アプリではゲーム変更を停止して提供者へ案内する。具体的な新規作成・切替は実装検証時の明示操作とする。

今回の変更は文書のみ。旧コード・Google上のデータ・デプロイは未変更。現行仕様は[要件](../01_requirements.md)・[ドメイン](../03_domain_model.md)・[データ](../05_data_model.md)、作業は[MVP実装](../tasks/03_active/mvp-implementation.md)・[画像撤去と事前生成セリフ](../tasks/03_active/ai-battle-dialogue.md)に反映する。
