# ADR 0002: 対戦セリフを管理画面で事前生成する

2026-10-26。採用。利用者がGASでのプレイ中リアルタイム生成を不許可とし、管理画面での作成管理を指示した。

ADR 0001の画像廃止は維持する。対戦後に別RPCで生成する部分は本ADRで置き換える。非同期でも対戦ごとのGAS／Gemini処理が発生するため、その案は採用しない。

提供者が管理画面でキャラ×勝敗のセリフを事前生成し、下書きを確認・採用して公開する。ゲームはbootstrap時に採用集を読み込み、保存済み対戦結果に対応する文をブラウザ内で表示する。プレイ中の生成、セリフ専用RPC、不足時の自動補充はゼロとする。未準備・管理AI障害は採用済み文または定型文で継続する。

管理画面・サーバー側管理認可・下書きと公開版・バックアップ拡張を実装範囲へ追加する。ゲームの勝敗や保存ルールは変えない。詳細は[設計](../specs/ai-battle-dialogue.md)、作業は[実装タスク](../tasks/03_active/ai-battle-dialogue.md)。実装・デプロイは未実施。
