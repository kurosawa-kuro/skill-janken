# ADR 0001: 画像生成を廃止し、生成AIを対戦後のセリフに使う

日付：2026-10-26。画像廃止は採用継続。対戦時の生成方式は[ADR 0002](0002-pre-generated-dialogue.md)で置換。合成維持の部分は[ADR 0003](0003-remove-synthesis.md)で置換。以下は当初判断の記録。根拠は利用者の「画像生成はオプションではなく、廃止」「生成AIはゲームに組み込みたい」という指示。

旧設計はGemini画像7枚と生成→WebP→登録を完成条件にしていた。設定した画像モデルにAPI無料枠がないため、この条件は無料運用と両立しない。画像なし表示を仮実装扱いにする判断を撤回する。

新設計では、カードはHTML/CSS・名前・効果文で成立させ、画像生成・画像登録・配信を製品から撤去する。生成AIは保存済み対戦への短いセリフに限定する。勝敗・得点・合成・所有は従来の固定ルールを維持し、AI障害でも定型文で続行できる。

画像生成を有料オプションとして残す案は、利用者の指示により不採用。生成AIを全面撤去する案も、ゲームへ生成AIを組み込む意図を満たさないため不採用。

要件と受入条件はdocs/01〜08へ反映し、AC16・AC17を改訂、AC24〜AC26を追加する。過去の画像疎通記録とアーカイブは履歴として保持する。保存スキーマ・既存Actions・素材を削除する操作は行わない。

詳細：[AIセリフ設計](../specs/ai-battle-dialogue.md)。実装：[画像機能撤去とAIセリフ](../tasks/02_backlog/ai-battle-dialogue.md)。設計採用はWeb v2への反映済みを意味しない。
