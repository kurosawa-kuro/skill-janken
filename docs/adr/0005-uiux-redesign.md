# ADR 0005: 選択と送信を分離し、あそびを主役にしたUIへ変える

2026-10-26。採用。利用者のUI/UX根本再設計依頼に対応する。

保存状態を大きく示す従来構成から、ホームの対戦入口と仲間を主役にする。4画面と結果モーダルは維持し、子どものゲームと提供者の管理画面を分離する。下部ナビは1列とし、大きい画面でも情報が狭い中央列に偏らないよう再配置する。

手を押すだけで対戦を送信する方式をやめ、手の選択と決定を分ける。ローカル操作が1段増えるが、誤タップで記録が増えることを減らし、仲間・スキル・手を自分で決めた後に送信できる。追加RPCは発生させない。再戦は手の選択に戻り、自動送信しない。

管理画面は仲間別の絞込みと「公開中／候補」の区分を設ける。チェックのない公開ボタンを無効にし、同じ下書きのチェックは画面内で保持する。保存領域の保留要求や公開版の競合制御をUIの都合で省略しない。

仲間の表現はCSS図形・表情・名前とし、画像生成・画像ファイル・配信経路は復活させない。ゲームルール、DB、AIの事前生成限定、本人限定公開を維持する。検証は利用者の指示どおり最後にまとめ、未検証の見た目を完成した観測結果として報告しない。

詳細：[UI/UX仕様](../specs/uiux-redesign.md)。
